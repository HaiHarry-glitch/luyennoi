🔑 Gemini API Keys

Nhập API key Gemini để dùng chức năng chấm điểm AI và gợi ý.
Lấy key miễn phí tại Google AI Studio.

🚀 Hướng dẫn lấy API Key (miễn phí)
  1. Truy cập 🔗 Google AI Studio
  2. Đăng nhập Google → bấm "Create API Key"
  3. Chọn project bất kì → copy key (bắt đầu bằng AIza...)
  4. Dán vào ô bên dưới → bấm Lưu keys

ℹ Key miễn phí có giới hạn 60 request/phút. Thêm nhiều key để xoay vòng khi hết quota.

🤖 Mô hình AI Gemini

Cơ chế: Hệ thống dùng fallback 2 vòng — vòng ngoài duyệt model, vòng trong duyệt API key. Khi gặp 429 / 5xx hoặc hết quota thì tự động chuyển sang model / key kế tiếp.
Mặc định (khuyên dùng): mỗi loại tác vụ dùng nhóm model phù hợp (xem bảng dưới). Nếu chọn 1 model cụ thể, model đó sẽ được gọi đầu tiên cho tất cả tác vụ, các model còn lại vẫn được fallback khi lỗi.
